# Исполнение в Codex

Методика и контракт едины: [отбор](../references/channel-selection.md), [JSON](../assets/channel-review-contract.md). Не копируй их в отдельную версию навыка.

Если среда предоставляет субагентов, для извлечения тем и оценки партий предпочитай GPT Luna, reasoning high, Fast/priority — только когда такой service tier реально доступен. В среде с идентификатором `gpt-5.6-luna` используй его; в иной среде сначала обнаружь доступные модели и параметры. Не выдавай слово Fast в промпте за настройку service tier. Не переключай незаметно на другую платную модель. Если модель/делегирование недоступны, выполни те же партии основным агентом и отметь фактический способ исполнения. Недоступность помощника не сокращает требуемое покрытие.

Поручение помощнику: «Оцени ровно IDs из batch.json по brief.json и channel-review-contract.md, используя только выданные публикации и ссылки. Верни JSON по каждому ID, не пропускай сбои/сомнения, не выдумывай аудиторию. Не изменяй бриф, не запускай рекламу и не отправляй сообщений. Путь результата: reviews/batch-N.json». Давай минимальный контекст, отдельный output каждой партии, не общий файл для одновременной записи. Доступ к исходным постам обязателен, описания каталога недостаточно.

Родитель управляет очередью и сверяет union IDs с candidates.json. Число одновременных помощников определяется доступными слотами и бюджетом. Перед завершением проверь реальный результат, а не только финальный текст помощника.
