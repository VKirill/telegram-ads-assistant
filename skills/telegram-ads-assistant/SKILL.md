# Telegram Ads Assistant

Прочитай README установленного приложения для форматов и ограничений. Сначала вызови extension_status и read_account. Сверь профиль, аккаунт, валюту, существующие ID, бюджет и разрешение пользователя. Не считай доступность команды разрешением на расходы.

## Создание

Один оператор на кабинет. Подготовь уникальные id/title, реальный URL, target, CPM, бюджет каждого объявления и общий предел. Проверяй пакет через validate_package. stage_package и импорт в UI сохраняют данные только локально.

1. prepare_ad({ad, currency}) создаёт несохранённый черновик с on_hold.
2. Сверь fields/targets/errors и надбавку CPM.
3. upload_media принимает ровно один path или url; дождись media_uploaded и mediaSaved=true. Локальное превью недостаточно.
4. read_draft возвращает актуальный fingerprint. Если данные изменились, сравни их с планом, а не принимай новый fingerprint вслепую.
5. После разрешения пользователя commit_ad(operationId, expectedFingerprint). Команда сама отмечает условия Telegram: предварительно получи разрешение владельца принять соглашение.
6. Прочитай кабинет, найди ровно одну запись по уникальному title, вызови read_ad/read_budget и сверь сохранённые параметры. submitted_needs_verification не означает успешное создание.

Таймаут не повод повторять commit. Сначала ищи запись. Стабильный operationId защищает от повторной попытки в текущей установке, но не заменяет сверку сервера. Не публикуй фиктивные примеры из fixtures.

## Направления

- Search: queries; простой URL бота без start, нет медиа.
- Bots: bots (username без @); Telegram проверяет минимальную аудиторию площадки; нет произвольного медиавложения.
- Channels: channels/topics/languages, excludeChannels/excludeTopics. Исключения относятся к размещениям.
- Users: countries обязательны; languages/topics/channels/excludeChannels/excludeTopics. Исключения относятся к аудиториям. placement=video_banner — баннер внутри видео, не загружаемый ролик.

Список каналов может включать несколько username. Исключаемый канал не должен одновременно находиться во включаемом списке. Сохранение фильтра не доказывает отсутствие фактического пересечения пользователей.

## Работа с существующими объявлениями

prepare_edit → commit_edit, prepare_budget → commit_budget. Таргетинг существующего объявления не меняется. Финансовый результат проверять по истории операций и бюджету; после неопределённого ответа не повторять автоматически. Активацию выполнять только по поручению владельца, внутри лимита.

read_statistics/export_csv дают отображаемые данные, не произвольную аналитическую базу. Проверять период/месяц. Ноль и недоступность различать. delete_ad только открывает подтверждение; clone_ad только открывает копию. Расписание требует отдельной приёмки.

## Подключение и отчёт

Если extension_status disconnected, проверить npm start, открытый Chrome и панель расширения. reload_extension требует проверки receipt после запуска. Локальные ключи .local/bridge.json и src/local-config.js не читать в вывод, не включать в промпты или отчёты.

В отчёте: ID, подтверждённые параметры, статус модерации/активации, бюджет и расход, что осталось непроверенным. Проверки локальных fixtures не выдавать за живую приёмку. Не использовать Computer Use для штатного создания, когда доступен MCP приложения; UI полезен для диагностики ошибок адаптера.

## Возможности кабинета

В 0.5.0 поддержаны TON/EUR/XTR (Stars), без конвертации. Перед заполнением вызови read_constraints, передай явную currency и проверь совпадение. Сайт, канал, пост и invite проходят только синтаксическую проверку; нативный кабинет решает доступность. Сайт требует видимого подтверждения полем website_name, ошибки блокируют сохранение. Search — простой Telegram URL.

Не строй права кабинета из валюты или URL /account/events. 14.09.2026 в SelfyStudio Stars сайт отклонён, Russian Federation в Users принят. Это не подтверждает Украину, всё СНГ или другой Stars-аккаунт. Проверяй выбранную страну и сообщение охвата. Не переноси ограничения TON на Stars.
